# Country Scenario C: Competing Energy Costs

A static course activity for evaluating AI readiness feasibility.

[Open the web app](https://tpicker.github.io/Country_AI_Feasibility_Scenario_C/)

## Scenario

A competing country offers significantly lower energy costs.

Based on Scenario C, slide 16 of the supplied feasibility assignment guidance.
Students enter their own analysis. The app does not generate recommendations or grade responses.

## Features

- Country assessment, with the course location dropdowns.
- Separate saved responses for each location when browser storage is available.
- Copy summary of responses and Print / Save PDF at the top and bottom.
- Manual-copy fallback when browser clipboard access is unavailable.
- Accessible labels, keyboard controls, and a responsive layout.
- A new recommendation field when Yes is selected; it is not applicable when No is selected.

## Privacy and saved work

Responses remain in the browser. The app does not submit responses or send them to a server.
Keep a copied summary or PDF before leaving, especially when browser storage is unavailable.
This app uses a separate storage key from the other scenario versions.

## Hosting and source

This repository contains a self-contained `index.html` with inline CSS and JavaScript.
No package installation, build step, external library, or server is required.
GitHub Pages serves the root of the `main` branch; `.nojekyll` keeps the site static.
